# Quantcast Live Tag and Measure template for Google Tag Manager Server Container (sGTM)

You can use this tag in Google Tag Manager Server Side containers to set up Quantcast Live Tag / Quantcast Measure.

It works based on Universal Analytics or Google Analytics 4 requests inside the Google Tag Manager Server Side container.

---

Check out our GTM integration guides:
- [Implement Quantcast Server Side Tagging with Google Tag Manager](https://help.quantcast.com/docs/implementing-quantcast-measure-server-side-with-google-tag-manager)
- [Implement Quantcast Live Tag with Google Tag Manager](https://help.quantcast.com/docs/implement-live-tag-with-google-tag-manager)

----
New feature released on May 14, 2026: Installing this code will provide Quantcast with access to your Google Analytics first party ID, which gives you the option to integrate your Quantcast campaigns with your Google Analytics account.
